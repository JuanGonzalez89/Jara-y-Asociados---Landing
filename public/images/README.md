# Guía de Imágenes para Jara & Asociados

Coloca las siguientes imágenes en esta carpeta (`public/images/`) para que la landing page funcione correctamente:

## Imágenes necesarias:

### Hero Section (Sección Principal)
- `building-hero.jpg` - Imagen principal del edificio moderno con detalles arquitectónicos
- `detail-1.jpg` - Detalle arquitectónico 1 (120x120px mínimo)
- `detail-2.jpg` - Detalle arquitectónico 2 (120x120px mínimo)
- `detail-3.jpg` - Detalle arquitectónico 3 (120x120px mínimo)

### About Section (Sobre Nosotros)
- `about-1.jpg` - Imagen de gestión profesional (300x300px mínimo)
- `about-2.jpg` - Imagen del equipo profesional (300x300px mínimo)
- `about-3.jpg` - Imagen de servicios especializados (300x300px mínimo)
- `about-4.jpg` - Imagen de administración integral (300x300px mínimo)

### Services Section (Servicios)
- `service1.jpg` - Gestión Integral de Consorcios (800x600px mínimo)
- `service2.jpg` - Habilitaciones Inmobiliarias (800x600px mínimo)
- `service3.jpg` - Asesoramiento Legal (800x600px mínimo)
- `service4.jpg` - Consultoría Financiera (800x600px mínimo)

### Buildings Section (Edificios)
- `building-admin.jpg` - Edificio administrado (600x800px mínimo)

### Contact Section (Contacto)
- `building-contact.jpg` - Edificio moderno para sección de contacto (800x1200px mínimo)

## Recomendaciones:

- Usa imágenes de alta calidad (mínimo 1920px de ancho para imágenes grandes)
- Formato recomendado: JPG optimizado o WebP
- Peso máximo por imagen: 500KB (optimiza con herramientas como TinyPNG)
- Asegúrate de que las imágenes tengan buena iluminación y composición profesional

## Imágenes temporales:

Si no tienes las imágenes todavía, puedes usar placeholders de:
- https://unsplash.com/ (edificios modernos, arquitectura)
- https://placeholder.com/ (imágenes temporales)
- https://picsum.photos/ (imágenes aleatorias)

## Paleta de colores para las imágenes:

Busca imágenes que complementen la paleta:
- **Azul primario:** #809bce
- **Amarillo/Dorado:** #fecb75
- **Gris oscuro:** #5f666d
